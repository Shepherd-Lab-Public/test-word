# test-word

Turns a seed Microsoft Word file into LaTeX and then a PDF. The project is run as a one-house seed household under the [Hawaii Method](https://github.com/Shepherd-Lab-Public/Hawaii-Method).

| Folder | What it holds |
|---|---|
| `legacy/` | Original files, such as the seed Word document. Kept unchanged. |
| `latex/` | The LaTeX source and the finished PDF. |
| `staff/lead/` | The Lead's memory: goals, state, products, to-do list, log, and notes. |

## Starting a session

Open a new Claude Code session in this folder and send:

> You are the Head House (Lead) for test-word. Read `staff/lead/HOUSEHOLD.md` and `staff/lead/STATE.md`, then follow CLAUDE.md.

Say "checkpoint" at the end of every session, so the work and decisions are saved to the repository.
